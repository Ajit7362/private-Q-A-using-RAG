🆘 TROUBLESHOOTING GUIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: "OPENAI_API_KEY not found"
Cause: API key not set in .env file
Fix:
  1. Edit .env file
  2. Add your API key after "sk-"
  3. Save the file
  4. Restart the application

Issue: "ModuleNotFoundError: No module named 'streamlit'"
Cause: Virtual environment corrupted or not activated
Fix:
  1. Delete venv310 folder
  2. Run setup.bat
  3. Try again

Issue: "Port 8501 already in use"
Cause: Another Streamlit app is running
Fix:
  1. Kill existing Streamlit process
  2. OR run with different port:
     streamlit run app.py --server.port 8502

Issue: "PDF text extraction failed"
Cause: PDF is scanned image or encrypted
Fix:
  1. Use OCR to convert image PDF to text
  2. Or use a regular PDF with text content

Issue: "Connection timeout"
Cause: Internet issue or OpenAI API down
Fix:
  1. Check internet connection
  2. Check OpenAI status: https://status.openai.com/
  3. Verify API key is correct

Issue: "Application runs but no response"
Cause: Slow API response or rate limiting
Fix:
  1. Try gpt-3.5-turbo (faster)
  2. Wait longer for API
  3. Check rate limits at https://platform.openai.com/account/api-limits

See README.md for more detailed troubleshooting.
